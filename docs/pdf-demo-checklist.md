## ลิงก์ที่ใช้ — สำคัญ

| ลิงก์ | ใช้กับใคร |
|---|---|
| **Public production URL** (ยืนยัน domain จริงที่ Vercel → Project → Settings → Domains) | **กรรมการ / ผู้ใช้ภายนอก / Manual QA หลัก** |
| Vercel Preview URL ของ PR | **ทีม dev เท่านั้น** — ติด Deployment Protection ต้องล็อกอิน **ห้ามส่งให้กรรมการ** |

## 1. ทดสอบบนเครื่องจริง (อย่างละ 1 เครื่อง)

- [ ] **iPhone (Safari)** — กดปุ่ม → ได้ไฟล์ หรือเห็นการ์ด "เปิดไฟล์ในแท็บใหม่"
      → แตะแล้วใช้ `Share → Save to Files` ได้
- [ ] **Android (Chrome)** — กดปุ่ม → ไฟล์ลงเครื่องทันที
- [ ] เปิดไฟล์ที่ได้ ตรวจ 2 จุด: คอลัมน์ขวาไม่ถูกตัด • สระ/วรรณยุกต์ไทยไม่เพี้ยน

> เอกสารถูกแปลงเป็นภาพ (rasterise) จึงเลือกข้อความในไฟล์ไม่ได้ — เป็นข้อแลกเปลี่ยนที่จำเป็น
> เพื่อให้สระ/วรรณยุกต์ไทยวางถูกตำแหน่ง 100%

## 2. ซ้อมแผนสำรอง (ต้องทำอย่างน้อย 1 รอบ)

- [ ] เปิด DevTools → Network → ตั้ง throttling เป็น **Slow 3G** หรือปิด Wi-Fi แล้วกดปุ่ม
- [ ] ภายใน ~12 วินาที ต้องเห็นข้อความ *"สร้าง PDF อัตโนมัติไม่สำเร็จ — เปิดหน้าต่างพิมพ์ให้แทน"*
      และหน้าต่างพิมพ์ต้องเปิดขึ้นมา → เลือก **"บันทึกเป็น PDF"**
- [ ] ปุ่มต้องกลับมากดได้ (ไม่ค้างที่ "⏳ กำลังสร้าง PDF…") และกดซ้ำแล้วต้องลองโหลดใหม่ได้

## 3. เตรียมของสำรองก่อนขึ้นเวที

- [ ] ดาวน์โหลด PDF ตัวอย่างเก็บไว้ในเครื่อง/อีเมลล่วงหน้า เผื่อเน็ตงานล่ม
- [ ] เปิดหน้าเว็บค้างไว้ในแท็บก่อนเริ่มนำเสนอ (ไฟล์ไลบรารีจะถูก cache หลังกดครั้งแรก)

## 4. สลับไป CDN ฉุกเฉิน

ถ้าไฟล์ใน `public/vendor/` มีปัญหา แก้บรรทัดเดียวใน `public/route2own.html`:

```js
const PDF_LIB_URL='https://cdn.jsdelivr.net/npm/html2pdf.js@0.14.0/dist/html2pdf.bundle.min.js';
```

## 5. เก็บ log หลังงานแข่ง

log ของ guard ทั้งหมดอยู่ในเครื่องที่ใช้สาธิตเท่านั้น (ไม่มีการเก็บฝั่งเซิร์ฟเวอร์)
เปิด DevTools Console ของเครื่องนั้นแล้วรัน:

```js
JSON.parse(sessionStorage.getItem('r2o_pdf_log') || '[]')
```

เก็บ 20 รายการล่าสุด แต่ละรายการมี `tag`, `version`, `path`, `userAgent`, `timestamp`

| Tag | ความหมาย |
|---|---|
| `PDF_DELIVERED` | สำเร็จ — มี `filename`, `bytes`, `elapsedMs`, `appliedScale` |
| `PDF_CANVAS_GUARD_TRIGGERED` | เอกสารสูงเกินเพดาน canvas ระบบลด scale ให้อัตโนมัติ (`fatal:true` = สูงเกินจนแปลงไม่ได้) |
| `PDF_CANVAS_BLANK_DETECTED` | ภาพที่ได้ว่างเปล่า ระบบตัดไป fallback แทนการให้ไฟล์เสีย |
| `PDF_LIB_LOAD_SLOW` / `PDF_LIB_LOAD_TIMEOUT` | โหลดไลบรารีช้า / เกิน 12 วินาที |
| `PDF_FALLBACK_PRINT` | ตกไปหน้าต่างพิมพ์ พร้อมเหตุผลใน `reason` |

**ไม่ควรพบ** `PDF_CANVAS_BLANK_DETECTED` หรือ `PDF_LIB_LOAD_TIMEOUT` บนเน็ตปกติ
ถ้าพบให้เก็บ log ไว้แล้วแจ้งทีม dev
